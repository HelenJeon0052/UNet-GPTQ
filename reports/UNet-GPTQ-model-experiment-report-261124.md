# U-Net-GPTQ 실험 개선 보고서
[2026.11.24]


뇌 FLAIR 실데이터의 M0 manifest 검증과 로컬 FP 모델의 100스텝 학습을 마쳤다. 저장한 EMA 체크포인트로 검증 슬라이스 518장의 잡음 예측 오차를 재현했다.

본 실험에서는 뇌 FLAIR로 학습한 FP 체크포인트를 기준 모델로 사용한다. 동일한 체크포인트에서 GPTQ W4를 생성하고, 후속 실험에서 독립 보정·평가 검사를 확보한 뒤, 동일 FP 체크포인트에서 생성한 W4와 짝지어 평가할 예정이다.

## M0 실데이터 manifest 검증 결과

로컬 실행 결과는 원본 HDF5를 읽기 전용으로 열고 승인된 scratch/brain-data/cohort/에 assignments.csv와 manifest.json을 생성했다. 공식 배치 목록과 대조한 로컬 파일명은 train 455개, val 460개 모두 일치했다. 전체 915개 가운데 FLAIR 64개 검사·1,014개 슬라이스를 포함하고 다른 시퀀스 851개를 제외했다. 포함된 64개 검사 모두 검토된 M0 시퀀스 판정 규칙을 통과했다.

| 최종 split | 검사 그룹 | HDF5 파일 | 슬라이스 | 공식 배정과의 관계 |
| --- | ---: | ---: | ---: | --- |
| train | 30 | 30 | 480 | 공식 train의 FLAIR 31개 중 개발에 쓴 1개를 dev로 이동 |
| val | 33 | 33 | 518 | 공식 val의 FLAIR 33개 유지 |
| dev | 1 | 1 | 16 | 공식 train에서 이동한 개발 사례 |
| **합계** | **64** | **64** | **1,014** | |

train/val 비율은 dev를 제외한 63개 검사 기준으로 **47.6% / 52.4%**다.
서로 다른 split 간 검사 그룹 중복과 원본 HDF5 SHA-256 중복은 각각 0건이었다. calibration/test는 기존 지정 근거가 없어 이번 실행에서 미지정으로 두었다.

| M0 검사 | 로컬 실행 결과 |
| --- | --- |
| 다중 코일 형상·코일 결합 | 64개 검사 모두 통과 |
| 헤더의 유효 주파수 범위 | 64개 검사 모두에서 헤더의 유효 ky 구간이 각 슬라이스에서 관측된 연속 비영 ky 구간과 일치했다 |
| FFT 왕복 상대 오차 | 최대 **4.22 × 10⁻⁷**, 허용치 **10⁻⁵** 이내 |
| RSS 공간 정렬 | 검토 기준 1% 초과 **0/64건** |

근거는 로컬 M0 실행 집계다.

## M1 로컬 FP 모델의 100스텝 학습 결과

fp-v1 실행은 100/100스텝을 완료했다. 배정표와 M0 manifest의 64개 항목이 일치했고, 현재 원본 64개의 파일 크기와 수정 시각도 manifest 기록과 같았다. 학습 로그 11개 구간의 슬라이스 수를 합산한 결과는 100장이었다. 저장한 seed로 샘플러를 재현했을 때 train 30개 검사가 모두 포함됐고 100장 사이에 중복이 없었다. 이번 실행은 학습 슬라이스 480장 중 20.8%를 사용했다.

| 측정 항목 | 측정 대상과 조건 | 결과 |
| --- | --- | --- |
| 학습 잡음 예측 MSE | 구간별 슬라이스 수로 가중한 전반 50스텝 평균과 후반 50스텝 평균 | 0.3826 → 0.0726 |
| EMA 검증 MSE | 50·100스텝 각각 val 518장 전체, 같은 순서·확산 시점·잡음 | 1.0536 → 0.9543 (9.4% 감소) |
| 저장된 EMA 재평가 | `best_ema.pt`를 다시 로드해 같은 val 518장 평가 | **0.9542563311**, 100스텝 로그와 절대 차이 **1.15 × 10⁻¹⁰** |

모델·EMA·옵티마이저 텐서에서 NaN/Inf는 발견되지 않았고, best_ema.pt의 가중치는 100스텝 체크포인트의 EMA와 정확히 일치했다.


## 100스텝 체크포인트 비교 — 동일 검증 32장의 잡음 예측 MSE

| 100스텝의 잡음 예측 방식 | MSE |
| --- | ---: |
| 마지막 optimizer 업데이트 직후의 가중치 | 0.0589 |
| 저장된 EMA 가중치 | 0.9546 |
| 모든 입력에서 잡음 0을 예측 | 1.0001 |

같은 슬라이스에 같은 확산 시점과 잡음을 적용했으므로, 두 모델의 MSE 차이는 이 표본에서 어느 가중치를 불러왔는지에 따라 발생했다. 고정 ema_decay=0.999로 100회 갱신하면 EMA 식에서 초기 가중치의 계수는 0.999¹⁰⁰ ≈ 0.9048이다. 짧은 학습에서는 EMA가 최근 업데이트를 천천히 반영하며, 이 표본의 EMA MSE는 0 예측 기준보다 약 4.5% 낮았다.

학습 직후 가중치의 0.0589는 32장 표본에서 측정한 값이다. 이를 518장 전체에서도 확인하려면 같은 순서·시점·잡음으로 해당 가중치를 재평가하면 된다. MRI 복원 품질은 M2에서 같은 multi-coil 관측값과 마스크를 사용해 magnitude/complex NMSE와 관측 k-space 잔차로 별도 평가할 예정이다.
