# U-Net-GPTQ 실험 개선 보고서
[2026.11.23]


이 연구는 뇌 FLAIR 확산 복원에서 U-Net 가중치를 GPTQ 4비트(W4)로 양자화할 때 영상 품질, 병변 주변의 신호·경계, 관측 k-space와의 일치도(data consistency, DC)가 얼마나 변하는지 평가한다. 11월 23일까지 무릎 MRI에서 학습한 DiffuseRecon prior로 FP16 기준선을 측정했고, FP와 W4를 같은 입력에서 비교하는 러너를 구현했다. 이 보고서의 측정값은 모두 FP16 실행에서 얻었다.

## 현재 파일럿과 본 실험의 범위

파일럿의 질문은 **무릎 prior를 뇌 FLAIR에 적용한 상태에서 양자화가 같은 모델의 복원 품질과 DC를 얼마나 바꾸는가**이다. 현재 FP 기준선은 인접한 두 복소 슬라이스의 실수부·허수부를 4채널로 입력하고, 코일 결합 영상에서 단일 코일 관측값을 합성한다. Score-MRI 및 SSDiffRecon은 학습 데이터와 학습 방식, 코일 처리 등 평가 조건이 달라 공개 PSNR·NMSE를 이 파일럿 수치와 직접 비교할 수 없다. [DiffuseRecon 실험 조건](https://arxiv.org/html/2203.04292v2#S3) · [Score-MRI](https://arxiv.org/abs/2110.05243) · [SSDiffRecon](https://arxiv.org/abs/2306.16654)

뇌 MRI에서의 양자화 효과를 평가할 본 실험에서는 **뇌 FLAIR로 학습한 FP 체크포인트를 확보**하고, 이 가중치에서 W4를 생성한다. 두 모델의 학습·평가 도메인을 뇌 FLAIR로 맞춰 무릎에서 뇌로 옮길 때의 도메인 불일치를 비교에서 제거한다.

## 입력 위상과 좌표계를 바꾸자 같은 FP 모델의 오차가 달라졌다

개발 볼륨 6002469의 슬라이스 7·8에서 입력 영상에 행과 열을 따라 부호가 번갈아 바뀌는 체커보드 위상을 적용하고 마스크와 관측 k-space의 좌표계를 함께 옮겼다. 아래는 동일 FP 모델, seed 1, FP16, DC 강도 0.5, coarse 100단계·refinement 20단계에서 보고된 두 슬라이스의 평균 magnitude NMSE다. 값이 낮을수록 참조 영상의 신호 크기에 가깝다.

| **복원 단계** | **변환 끔 (OFF)** | **변환 켬 (ON)** |
| --- | --- | --- |
| 초기 복원 (coarse) | 0.52007 | 0.08417 |
| 최종 복원 (refined) | 0.29307 | 0.02374 |

같은 쌍의 zero-filled 기준값은 0.03437이었다. 최종 FP의 ON 값은 OFF 대비 91.9% 낮았다. 비교 대상은 한 개발 볼륨의 입력 표현 두 가지다. W4의 영향과 병변 보존 여부는 본 실험에서 평가한다.

최종 복원 영상이 관측값과 얼마나 일치하는지 확인하기 위해, 측정된 k-space 위치에서 복원값과 관측값 사이의 상대 L2 오차(DC 잔차)를 계산했다. 슬라이스 7·8의 평균 DC 잔차는 위상 변환을 껐을 때 **0.01615**, 켰을 때 **0.00865**였다.

입력 좌표 변환의 정확도는 복원 전에 확인했다. 원본 관측 k-space를 변환 후 좌표계로 옮긴 뒤, 변환한 영상과 마스크에서 다시 계산한 관측 k-space와 비교했다. 상대 L2 오차는 슬라이스 7·8에서 **1.60×10⁻⁷**, 슬라이스 8·9에서 **1.30×10⁻⁷**이었다. 두 쌍은 같은 볼륨의 슬라이스 8을 공유한다.

## 비교 절차와 평가 지표의 개선

가중치만 바꿨을 때 발생하는 차이를 읽으려면 두 모델의 입력과 복원 조건이 같아야 한다. 또 복소 MRI에서는 신호 크기가 같아도 위상이 달라질 수 있어 두 오차를 따로 기록해야 한다.

### FP와 W4의 비교 조건

| **항목** | **구현 또는 정리한 내용** |
| --- | --- |
| **모델과 가중치** | 러너가 FP와 W4 모델을 각각 새로 불러온다. Conv2d GPTQ는 입력 패치로 보정 통계를 수집하고 원본 체크포인트 해시와 양자화 계층 정보를 저장한다. |
| **샘플링과 재현성** | 같은 관측값·마스크로 coarse와 refinement를 실행한다. 러너는 FP 반복 실행과 전역 난수 상태의 시작·종료 해시를 비교하는 기능을 제공한다. 위 FP 파일럿은 seed 1로 각 조건을 한 번 실행했다. |
| **오차의 발생 위치** | 진단 경로는 W4 궤적의 같은 입력과 시점을 FP denoiser에 주어 출력을 비교한다. 본 실험에서는 한 단계의 DC 전후 차이와 각 모델의 최종 복원 오차까지 연결해 분석한다. |
| **실행 비용** | 현재 W4 경로는 역양자화된 가중치로 부동소수점 연산을 수행한다. 실제 INT4 커널의 속도·메모리 효과는 해당 커널로 측정한 뒤 보고한다. |

### v2 지표 정의와 검증 결과

세 평가 경로(`image_metrics`, 파일럿 분석기, FP/W4 러너)는 같은 슬라이스 단위 지표를 사용한다. Magnitude NMSE는 신호 크기 차이의 제곱합을 참조 영상의 에너지로 나누고, complex NMSE는 같은 분모에 복소 차이의 제곱합을 사용한다. Magnitude PSNR의 peak는 각 참조 슬라이스의 최대 magnitude다. 요약값은 슬라이스별 NMSE와 PSNR(dB)의 산술평균이다. [지표 정의와 파일 형식](../docs/metric_definitions.md)

사례 6002469의 FP 실행 세 건에서 저장된 입력과 복원 영상으로 지표를 다시 계산했다. 슬라이스 7·8은 위상 변환을 끈 실행과 켠 실행을 모두 사용했고, 슬라이스 8·9는 변환을 켠 실행을 사용했다. 각 실행에서 두 슬라이스의 초기 복원(coarse)과 최종 복원(refined)을 각각 평가했다. 총 12개 결과에서 다섯 지표(magnitude NMSE, complex NMSE, magnitude RMSE, magnitude PSNR, DC 상대 L2)가 모두 실행 당시 기록한 값과 상대 허용오차 10⁻⁶ 이내에서 일치했다.

**로컬 테스트.** 2026년 11월 23일 로컬 환경에서 `PYTHONPATH=src python -m pytest -q tests`를 실행해 **36개 모두 통과**했다. 지표 테스트 8개에는 실제 PyTorch 텐서로 세 평가 경로의 슬라이스별 NMSE·PSNR과 평균을 대조하는 통합 테스트가 포함된다. 참조 영상의 부호만 뒤집은 예제에서 magnitude NMSE는 0, complex NMSE는 4, magnitude PSNR은 +∞였다. 참조 영상 전체가 0인 예제에서는 두 NMSE와 PSNR 모두 NaN이었다. ## 뇌 FLAIR 본 실험 계획

다음 이정표는 독립 검증 사례에서 복원 품질을 확인한 뇌 FLAIR FP 모델을 확보하는 것이다. 그 가중치와 전처리·측정 연산자·샘플러가 고정돼야 W4에 따른 변화량을 해석할 수 있다.

### FP 체크포인트 확보와 복원기 검증

`brain_ddpm_scratch_v1`은 U-Net-GPTQ 저장소 루트에 추가하는 패키지로, 기존 GPTQ 비교에 사용할 뇌 FLAIR FP 체크포인트를 만드는 선행 단계다. 코드에서 학습에는 완전 샘플링된 코일 데이터를 결합한 복소 영상을, 복원 평가에는 코일별 관측 k-space와 취득 마스크를 사용한다.

| 단계 | 구현 및 검증 결과 |
| --- | --- |
| **M0 · 데이터 선별** | HDF5의 acquisition과 프로토콜 메타데이터로 볼륨을 선별한다. 코일 결합, FFT 왕복 오차, 유효 주파수 범위, 참조 RSS 영상과의 공간 정렬을 점검하고 학습·검증 manifest를 작성한다. |
| **M1 · FP 학습** | 한 슬라이스의 실수부와 허수부를 두 채널로 구성해 PyTorch DDPM U-Net을 FP32로 처음부터 학습한다. |
| **M2 · multi-coil 복원** | FP 모델을 관측 k-space와 취득 마스크에 연결하고, 관측된 중심 영역에서 코일 감도 지도와 정규화 스케일을 계산한다. |

**실제 뇌 FLAIR 학습과 GPTQ 비교.** 다음 단계에서는 환자 단위(환자 연결이 어려우면 검사 단위)로 데이터를 분할해 학습하고, 독립 검증 사례에서 위상·스케일·마스크와 FP 복원 품질을 점검한 뒤 기준 체크포인트의 해시를 고정한다.

확정한 FP 체크포인트에서 W4를 생성하고 양자화 대상·제외 계층을 기록한다. 같은 관측값·마스크·정규화·DC·denoiser 호출 수(NFE)·난수열·활성값 정밀도로 두 모델을 평가한다. 전체 영상, 병변 ROI와 경계, 미관측 주파수의 오차 및 관측 k-space 잔차에 대해 환자별 W4−FP 차이를 구하고 여러 seed의 반복은 환자 안에서 집계한다.

### 종단 병변 평가와 후속 개선

동일 환자의 두 시점에 참조 분할과 대응 복원 영상이 있으면 병변 부피 변화 오차 EΔV = \|(V̂₂ − V̂₁) − (V₂ − V₁)\|를 mL로 비교한다. V̂는 같은 고정 분할 절차로 복원 영상에서 구한 부피, V는 참조 부피다. 두 시점의 오차가 서로 상쇄될 수 있어 각 시점의 절대 부피 오차도 함께 보고한다.

가중치 단독 비교 후에는 같은 W4를 고정하고 전체 A4, 선택 시점 A8, 동일 예산의 무작위 시점 A8을 비교한다. 고주파·병변을 고려한 보정이나 저랭크 잔차 보완은 각각 독립 조건으로 평가한다.
